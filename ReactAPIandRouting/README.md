# Apple.com Full-Stack Replica
📱 Project Overview A fully responsive, full-stack replica of the official Apple.com website designed to mimic its iconic minimalist aesthetic, seamless navigation, and dynamic product showcases. This project integrates a modern React frontend with a robust Node.js backend and a MySQL database to manage product data, alongside third-party API integrations for live content delivery.


## ✨ Key Features
Pixel-Perfect UI/UX: Meticulously styled interface replicating Apple's signature typography, layout grids, navigation bar, and interactive product sections.

Dynamic Product Routing: Utilizes React Router to handle multi-page navigation seamlessly (including pages for Mac, iPhone, individual product specs, and dynamic product parameter routing like /iphone/:productID).

RESTful Backend API: Built with Node.js and Express to handle server-side logic and securely serve data to the frontend.

Relational Database Integration: Uses MySQL to store and manage structured product catalogs, specifications, and relational data.

Live YouTube Integration: Implements a custom component fetching and shuffling live videos from Apple’s official YouTube channel via API/RSS feeds, complete with reactive thumbnails, titles, descriptions, and publication dates.

Error Handling & Fallbacks: Features custom 404 error pages and robust error handling for API requests and client-side routing.


## 🛠️ Tech Stack
Frontend: React, React Router, CSS3 / Modern Flexbox & Grid

Backend: Node.js, Express.js

Database: MySQL

APIs & Tools: YouTube Data API v3, Git, Vite
